SECURITY.md
Reporting a vulnerability

If you discover a security issue in Sophia, please email jsmithteaching@hotmail.com with details. We aim to acknowledge reports within 72 hours and provide a remediation plan within 7 business days for high‑severity issues.

Please include

A clear description of the issue and potential impact

Steps to reproduce (PoC if possible)

Affected version/commit and environment details

Responsible disclosure

Do not publicly disclose before a fix is available and coordinated with us.

Avoid testing against production systems without prior consent.

Do not access, modify, or exfiltrate data you do not own.

Scope

Code in this repository (backend, OpenAPI, scripts)

Default Docker/Podman dev environment

Out of scope

Third‑party services not controlled by this repo (e.g., your own Firebase/S3 accounts)

Social engineering or physical attacks

Credits and thanks

We credit reporters in release notes if you wish (optional). No bug bounty program at this time.
